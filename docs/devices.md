# 设备连接与预览

游戏机的画面通过 HDMI 输出到控制机采集卡，盒子的键鼠输出连接到游戏机。控制机运行 OK-WW-DualPC。

本页参数修改后自动保存，顶部显示保存状态。未填完整的参数以草稿保留，重开软件可继续编辑；手动采集与裁剪开关关闭后也保留已填写的值。点击「开始」或设备调试中的「仅应用设备配置」时，软件校验参数并连接设备。

## 采集卡

在「双机设置」的「视频采集」区域，点击采集设备选择框旁的「检测设备与参数」，一次读取当前采集后端发现的所有视频设备及其支持的分辨率、图像格式和帧率。切换采集卡直接使用本次检测结果，三个参数列表按设备能力联动，无需再点读取参数。更换设备或驱动后重新检测即可；单个设备读取失败会显示原因，其余设备仍可选择。设备已连接时，先点击「停止」释放设备再检测。高级设置仍保留手动参数输入。

选好参数后，点击本页右上角的「开始」自动连接并运行任务；「停止」会结束自动任务并断开采集卡与盒子。F9 只暂停或继续自动任务。只需预览或测试时，展开「设备调试」并选择「仅连接预览」。原生版使用 DirectShow 或 Media Foundation。

任务页的「停止」只结束当前任务并释放按键，采集、预览和盒子连接继续保留，其他任务可以复用连接。任务准备期间点击「取消启动」也不会断开设备；正在连接时会完成连接，但不会随后启动已取消的任务。预览区「紧急停止键鼠」同样保留设备连接。需要断开设备时，使用双机设置右上角的「停止」。

驱动报告的模式不一定能在当前连接下稳定工作。状态中的协商参数是驱动返回值，实际收帧率是程序最近收到画面的速率。显示器刷新率和游戏渲染帧率应在游戏机侧查看。

如果黑屏或打不开采集设备，先退出占用同一采集卡的软件，例如 OBS 或另一个 OKWW 实例，再检查游戏机输出、驱动、分辨率与格式组合。NV12、YUY2 等格式的可用范围由设备决定；P010 暂未启用。

## 键鼠盒子

当前仅支持 KMBox Net。在盒子屏幕上查看 IP、端口和 UUID，填入对应配置项；控制机与盒子需要网络可达。参数修改后自动保存，连接前仍会校验。

点击「开始」连接设备并运行任务；只需检查连接时，使用「仅连接预览」，再点击「测试移动」。连接成功表示协议通信正常，实际鼠标落点和游戏输入仍需检查。

「测试移动」以向右、向下各 40 像素为校准目标。相对移动盒子无法读取游戏机鼠标位置，移动倍率、系统加速度、游戏内鼠标模式和分辨率都会影响最终落点。横向和纵向移动倍率分别控制两个方向的位移换算；更换分辨率后应重新检查。

任务运行中也可测试移动。测试与脚本输入串行发送，保留当前按键和鼠标按住状态，任务继续运行；后续脚本移动可能覆盖测试位置。状态区显示发送结果，连接失败时显示原因。

## 预览

预览帧率可选 30、60、120、144、165、240 和无限制。可以打开独立窗口并置顶，画面保持原始比例。

内嵌和独立预览按窗口实际像素与屏幕缩放比例显示，最高保留采集原始分辨率。缩小画面时保留细线与文字，放大时平滑显示；调整窗口大小后自动更新。两个窗口同时打开时共用一次画面转换。

预览帧率只控制界面刷新，不改变采集卡的协商参数。「无限制」也不意味着超过设备实际供帧速度。

## 软件延迟指标

任务启动时会尝试预留 64 MiB 已提交的应急内存。图像转换或文字识别发生内存不足时，释放这块缓冲并重试一次当前识别；已经发送的键鼠指令不会重发。持续内存不足时结束任务并显示原因，同时跳过额外的错误截图分配。应急缓冲用于短时内存峰值，不能代替足够的系统可用内存。

NV12、YUY2、UYVY 和 RGB 预览使用批量图像转换；识别链路对同一帧复用转换结果，新帧到达后再更新。Media Foundation 在处理当前帧时提前请求下一帧，仍只保留最新画面。

KMBox Net 状态显示最近通信的应答中位值与 P95。这个指标从主机发送命令算到匹配的协议应答，不包含盒子 USB 报告生效、游戏处理或显示器响应。

画面年龄从驱动回调开始计算，不能当作 HDMI 输入总延迟。相对鼠标定位仍保留复位、分段间隔和按钮按住时间；最后一段发送后不再重复等待一次。更改复位或移动间隔前，应确认落点与点击可靠性。

Media Foundation 异步读帧接口见 [Microsoft 文档](https://learn.microsoft.com/en-us/windows/win32/api/mfreadwrite/nf-mfreadwrite-imfsourcereadercallback-onreadsample)。
