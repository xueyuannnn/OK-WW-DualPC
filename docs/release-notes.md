# OK-WW-DualPC 0.2.0 预览版

鸣潮双机版。控制机通过采集卡识别画面，通过 KMBox Net 操作游戏机。内置战斗与任务由 C++ 执行，角色工坊和通用脚本使用 Python。

## 双机与预览

- 一键连接采集卡和盒子并运行任务，支持取消准备、暂停和停止。
- 任务停止或取消准备后保留设备连接，预览与测试仍可使用；在双机设置点击停止才断开设备。
- 一次读取采集设备及支持参数，可选择分辨率、帧率和图像格式。
- 双机设置参数自动保存，保留未填完的草稿，连接时校验；取消保存设置按钮。
- 键鼠控制统一使用 KMBox Net，提供鼠标移动测试和移动倍率设置。
- 支持任务运行中测试移动，保留当前按键状态，显示发送结果或失败原因。
- 连接界面不再提供演练模式，参数校验通过后连接实际设备；离线验证由独立测试运行。
- 内嵌预览和独立预览窗口，支持置顶、等比显示和独立帧率设置。
- 预览适配窗口尺寸和高分屏，最高保留采集原始分辨率；缩小保留细节，放大平滑显示，录制预览同步适配。

## 战斗与任务

- 切换队伍代码后清除旧检测状态，下次启动重新识别角色与代码模式；修正短动作条把无目标图案当成敌人的判断。
- 任务预留识别应急内存，短时内存不足时释放缓冲并重试一次识别；持续不足时显示具体原因。
- 支持 57 名内置角色，运行栏显示当前队伍、角色和代码模式。
- 每日任务、4C 声骸循环、噩梦巢穴、周常乐园和材料副本。
- 4C 可选起始分类、位置和每个副本的轮数；周常可设置流派、选卡和商店购买策略。
- 声骸合成、强化调谐、主属性重构，以及已保存账号的多账号日常。
- 实时触发设置自动保存；定时计划使用年、月、日选择和独立时间输入。

## 工坊与脚本

- 导入导出 OK-WW / OK-WW-E 标准 Python 队伍 ZIP，按队伍切换内置或工坊连招。
- 代码切换在后台执行，复用工坊管理环境；修改后的工坊代码及辅助模块仍会重新检查。
- 代码库展示队伍头像、方案说明、作者和版本，支持周期同步及离线导入。
- 通用脚本编辑、中文动作模板、预览区域键鼠录制、循环执行和 `.okscript` 导入导出。
- 图片标注、脚本资源管理，以及日志、通知和中断恢复设置。
- 关于页提供联系邮箱、复制地址和邮件入口。

## 下载与运行

下载 Windows x64 完整包 `OK-WW-DualPC-full.zip`，完整解压后运行 `OKWW-DualPC-Native-Dev.exe`。首次使用需要配置采集卡和盒子；连接后可通过「测试移动」检查鼠标输出。

源码包为 `OK-WW-DualPC-source.zip`，构建方法见 `docs/development.md`。下载文件可使用 `SHA256SUMS.txt` 校验。

## 使用限制

当前为预览版，仅支持 KMBox Net。采集格式和实际帧率取决于设备与驱动。暂不支持 FFmpeg、P010 和直接上传工坊。

工坊中需要额外依赖、调用本机键鼠或使用未支持角色的代码可能需要适配。请只导入可信代码。不同设备和游戏版本仍需实际测试。
