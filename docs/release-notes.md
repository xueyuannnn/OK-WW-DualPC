# 0.2.0-beta.12

本次主要调整每日任务和副本刷取。

- 每日副本领奖后复核体力进度，修复短暂漏识别或领奖进度未同步导致任务提前结束的问题。
- 每日奖励先领，再继续刷设定的副本额度；补目标已刷的份数计入总次数。
- 优先双倍领取，剩余次数或体力只够一份时单倍。体力魔方只用于补完每日目标，每天最多 4 个。
- 每日流程复用已打开的副本指南，减少退出、重新打开页面的等待。

无音区每份领取计一次，双倍计两次。当天体力和备用体力不足时结束，不为凑满刷取次数额外消耗魔方。
