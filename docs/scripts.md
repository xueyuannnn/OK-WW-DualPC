# 脚本与模板

## 编辑和运行

「脚本」管理通用 Python 任务，「角色代码」管理角色队伍连招。这两个入口使用各自的脚本格式。

点击「新建」，输入以字母或下划线开头的英文文件名。编辑器提供行号和语法着色；「保存」或 Ctrl+S 写入源文件。切换脚本、运行或退出时，有未保存修改会提示处理。复制会创建独立文件；删除会把源文件移到个人配置的 `deleted-scripts`。

左侧操作模板来自原版任务 API。可以按名称或说明搜索，双击填写参数并插入代码。参数支持数字、文本和 Python 表达式。脚本加载时按原版生命周期初始化配置，任务页显示其配置项；简单数值、开关和列表使用相应控件，嵌套结构保留 JSON 输入。

一次性任务可设置循环次数，或勾选「持续循环」，然后点击「运行」。实时任务可以在实时触发页启停；从编辑器运行实时脚本，会启用该项并启动实时任务扫描。停用实时脚本会终止其当前执行并释放输入，其余已启用的实时任务继续扫描。F9 暂停整个自动执行器，任务页「停止」结束执行并保留设备；双机设置的「停止」断开设备。

循环设置和任务参数自动保存，代码需要点击保存。实时触发页的参数无需移开焦点即可自动保存，并显示保存状态；运行中修改自定义实时脚本的参数，从下一次触发开始生效，当前这次执行继续使用原值。修改代码、循环设置或任务类型前仍需暂停。外部编辑器修改当前文件后，空闲状态下可重新加载；编辑器有未保存修改时会先提示。运行中的进程保持已加载代码，暂停并刷新后才使用新文件。

## 录制

先连接采集卡和盒子，暂停自动任务，再点击「录制」。录制窗口显示采集画面；点击「开始录制」后，在该画面内操作键鼠，输入会同步发送到游戏机。录制保留按下、松开和事件间隔，支持组合键、长按、点击、拖动及滚轮。

录制只接收预览画面中的输入。它不监听游戏机上独立连接的物理键鼠，也不在其他本机应用中录制。离开录制画面的键盘焦点会释放按键；快捷键可以立即暂停输出。

点击「停止录制」后可写入脚本。已有脚本只替换 `run` 方法，保留初始化配置与其他方法；没有选择脚本时会新建录制脚本。代码可以继续编辑。设备失联或录制输入积压时会停止输出。

## 导入和导出

「导入脚本包」接收原版 `.okscript` 文件，保留包内 Python 源码、清单和资源。导入后默认不启用任务。运行使用当前双机设备配置；脚本中的窗口启动设置不会切换采集卡或本机键鼠后端。

「导出脚本包」打包当前脚本所属目录中的任务及资源，使用原版格式。角色队伍 ZIP 应在「角色代码」页导入。需要额外 Python 库、直接调用本机键鼠或依赖特定游戏版本的代码仍需单独适配；Python 兼容进程不是安全沙箱。

## 模板

「模板」页可以截取当前采集画面，也可导入图片。选中图片点击「标注」，或双击图片，在画面中拖动框选后添加区域。名称和 X、Y、宽、高都可手动修改；保存时检查名称与边界。

模板名称应唯一。自定义模板与内置模板同名时，内置识别保持原有模板。删除图片会移除其标注，原图留在个人配置的模板回收目录。

「保存到脚本资源」将当前标注写入个人配置的 `ok_tasks/assets`，并可生成 `LabelEnum.py`。资源图保留原始尺寸和标注位置，只保留标注区域的像素；原截图不变。之后导出脚本包会包含这些资源。新的运行进程会载入更新后的模板。

## 多账号日常

在任务页启动「多账号日常」。软件先完成当前账号的每日任务，再返回登录框，从已保存列表选择未完成账号；确认显示账号一致后登录并继续。每日流程读取「每日任务（基础）」的设置。

任务不输入账号密码或处理验证码。账号显示不可读、切换后不一致、达到数量或翻页上限时会停止并说明原因。完成所有可识别的已保存账号后停留在登录界面。
