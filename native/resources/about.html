OK-WW-DualPC · OK-WW双机版 是面向鸣潮的双机自动化项目， 通过采集卡读取游戏画面，通过 KMBox Net 或 MAKCU 发送键鼠操作。

支持自动战斗、每日任务、副本循环、声骸管理与角色代码工坊。 内置任务与角色由 C++ 执行，工坊队伍使用独立 Python 运行环境。

本项目免费开源，应用代码遵循 AGPL-3.0。第三方框架、组件和游戏资源 保留各自的许可证、附加条款与版权，使用和分发前请阅读随附说明。

本项目基于 OK-WW、OK-WW Enhanced 和 ok-script 开发，感谢原作者与社区贡献者。

自动化功能可能影响账号安全，请了解游戏相关规则后使用。
